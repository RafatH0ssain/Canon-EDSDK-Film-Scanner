Preview

Film is the real pipeline: it measures the film base, divides out the orange mask and inverts density properly. Linear is the old v0.1 flip, kept so you can see the difference — on colour negatives it comes out cyan. Untick Invert to positive to see the negative itself.

Put the loupe over the rebate — the clear unexposed border between frames — then press this. Measuring the real base beats the automatic guess, which assumes the densest part of the picture is close to base density. The area you pick carries over to the saved positive, where the same rebate is re-measured at full resolution: a capture and a live-view frame are on different scales, so the number itself would mean nothing there.

These settings drive both the preview and the positive written after a capture, so the file matches what you judged here. The capture itself is always kept exactly as the camera wrote it.

Focus loupe

Click anywhere on the image to move the loupe. This enlarges pixels the camera already discarded when it downscaled the live-view stream.

Focus peaking

Sharp edges are marked red. Computed here rather than read from the camera, so it works in autofocus mode — meaning you can drive focus and watch peaking at the same time.

Focus drive

←→ fine · Shift medium · Alt coarse

Fine is a single step of the SDK's smallest size — the finest move EDSDK offers, so nothing below it exists. Medium and coarse send several steps, because on an RF macro lens one step is far too small to see without the loupe.

Press Enter or click away to apply. A relative path resolves against the project folder, and the folder is created if it does not exist. Changes last for this session — to make one permanent, set capture.output_dir in config.yaml.

Waited after the last thing that could have disturbed the rig, before the shutter fires. On a copy stand, residual vibration is the main cause of soft scans.

Uses the inversion settings above, so the file matches what you judged on screen. The original is never modified or overwritten.

Auto keeps the depth the capture had: a 16-bit TIFF from RAW and from HEIF, a JPEG from a JPEG. Forcing JPEG on a RAW throws away 8 bits, which is a fine proof and a poor master.

All lossless. Measured on real 32 MP positives: none 194 MB in 0.2 s, LZW 162–178 MB in 2.3 s, deflate 74–81 MB in ~5 s. LZW hardly compresses 16-bit continuous tone and is what you get anyway if nothing is set, so deflate is the default.
